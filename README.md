## 🔥 Streak Challenge & Leaderboard

A gamified, **paid** 30-day daily-practice system:

```
Day 1 ──► Day 2 ──► Day 3 ──► ... ──► Day 30 ──► 🏆 Leaderboard Rank
  🐍         🐍         🐍                🐍
10 Qs      10 Qs      10 Qs             10 Qs
```

1. 💳 User pays the dynamic streak price (admin-configurable, default ₹99) via Razorpay
2. 🔓 Unlocks `DailyPractice` — 10 AI-generated Python questions every day
3. 📊 Progress + streak count tracked in `localStorage` + Firestore
4. 🎯 Results shown on `StreakResult`
5. 🏆 Rankings surface on the global `Leaderboard`
6. 🛠️ Admins manage everything from `AdminStreak`

> 👑 Admin account gets the Streak Challenge auto-unlocked for free on login.

## 🌍 Geo Pricing & Global Payments

- 📍 On load, the app silently detects the visitor's country (`detectGeoPrice`)
- 🇮🇳 **India** → prices in ₹ INR, checkout via **Razorpay**
- 🌍 **Everywhere else** → prices converted to local currency, a banner invites the user to pay via **PayPal**, and checkout opens a pre-filled `paypal.me` link
- ❌ The geo-banner is dismissible per session

## 🛡️ Anti-Cheat Exam Engine

Every mock test runs inside a locked-down, proctored environment:

<div align="center">

| Protection | Behavior |
|:---|:---|
| 🖥️ **Fullscreen lock** | Forced fullscreen; exiting triggers a warning + auto-return |
| 🚫 **Tab-switch detection** | 3 switches = automatic disqualification |
| ⌨️ **Copy-paste block** | Ctrl+C / Ctrl+V / Ctrl+A / right-click disabled |
| 📹 **Screen-record block** | Intercepts `getDisplayMedia` capture attempts |
| 🔍 **DevTools detection** | Flags open dev tools / abnormal window sizing |
| 💧 **Live watermark** | Name + email watermarked across every screen |
| ⏱️ **Auto-submit** | Test force-submits with an alarm on timeout |
| 🌫️ **Blur-on-blur** | Content blurs instantly if focus is lost |

</div>

## 🏗️ Architecture

```
┌───────────────────────────┐        ┌─────────────────────────────┐
│         Frontend            │        │           Backend             │
│   React (CRA) on Vercel     │◄──────►│   Node/Express on Render      │
│   faizupyzone.shop          │  REST  │   (render.yaml)                │
└──────────────┬──────────────┘        └────────────────┬────────────────┘
               │                                          │
               ▼                                          ▼
      ┌────────────────────┐                     ┌───────────────────────┐
      │     Firebase          │                     │  Vercel Serverless     │
      │   • Auth                │                     │  Functions (api/)       │
      │   • Firestore DB        │                     │  • generate-questions   │
      │   • firestore.rules     │                     └───────────────────────┘
      └────────────────────┘
               │
               ▼
      ┌────────────────────┐        ┌────────────────────┐
      │  Razorpay (India)      │        │  PayPal (Global)      │
      └────────────────────┘        └────────────────────┘
```

- 🧠 **State management:** React Context (`AuthContext`, `CartContext`, `ThemeContext`, `GeoContext`) — no Redux
- 🧭 **Routing:** Custom hash-based router (`window.location.hash`) with `popstate` handling — no react-router
- 💾 **Persistence:** Firestore for orders/products/certs, `localStorage` for cart/theme/streak state

## ⚙️ Getting Started (Local Setup)

### ✅ Prerequisites
- Node.js (LTS)
- npm or yarn
- A Firebase project (Auth + Firestore enabled)
- A Razorpay account (test/live keys)

### 🖼️ Frontend

```bash
git clone https://github.com/luckyfaizu3-eng/faizu-pyzone.git
cd faizu-pyzone
npm install
npm start          # runs on http://localhost:3000
```

### 🖥️ Backend (Render service)

```bash
cd backend
npm install
node server.js
```

```env
REACT_APP_FIREBASE_API_KEY=
REACT_APP_FIREBASE_AUTH_DOMAIN=
REACT_APP_FIREBASE_PROJECT_ID=
REACT_APP_RAZORPAY_KEY_ID=
REACT_APP_GA_MEASUREMENT_ID=G-XXXXXXX
```

```env
RAZORPAY_KEY_SECRET=
FIREBASE_ADMIN_CREDENTIALS=

```

> ⚠️ Both `.env` files are git-ignored. Never commit live Razorpay secrets or Firebase admin keys.

## 🔒 Security & Data Protection

- 🔥 `firestore.rules` — production Firestore access rules
- 🌐 `cors.json` — CORS policy + anti-piracy hardening (screen-record block, desktop-mode enforcement)
- 🔑 Razorpay secret key lives **only** on the backend/server side — never in the React bundle
- 🧾 Coupon-based free unlocks are logged with a distinct `FREE-COUPON-<code>-<timestamp>` payment ID for audit trails
- 👮 Admin routes gated by exact-match email check (`ADMIN_EMAIL`) in addition to Firebase custom claims
